# Computational & Simulation Sandbox 🧪⚙️

Welcome to my personal learning repository! This space serves as a collection of scripts, prototypes, and side projects built to explore core concepts in **computational mechanics, numerical methods, physical modeling, and scientific computing**. 

The goal of these projects is fundamental mastery—building algorithms, grid loops, and visualization tools from the ground up to understand how simulation engines work under the hood.

---

## 📂 Repository Structure

* **`cellular-automata/`** — Grid-based transition simulations, featuring custom rule implementations and real-time animations with Matplotlib.
* **`numerical-methods/`** *(in progress)* — Custom linear algebra solvers, matrix factorizations, and finite-difference grid routines.
* **`mechanics-simulations/`** *(in progress)* — Physical system models and thermal-driven analysis utilities.

---

## 🛠️ Tech Stack & Tools
* **Languages:** Python (NumPy, Matplotlib), C++ (for high-performance modules)
* **Environment:** Linux (WSL Fedora) and Windows. Ps: It just depends on how I feel tbh.. 
* **Tools:** Git, GitHub, Visual Studio Code
